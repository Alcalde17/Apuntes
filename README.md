# 🚀 Proyecto de Data Science y Machine Learning

¡Bienvenido a mi repositorio de aprendizaje y proyectos de Data Science! Aquí recopilo mis prácticas, análisis de datos y modelos de Machine Learning desarrollados en Python.<br>
Aquí iré publicando paulatinamente mis avances en el sector así como apuntes que haga a lo largo de mi formación.

## 📁 Estructura del Proyecto

El proyecto está organizado en diferentes módulos según la tecnología o concepto abordado:

* **`/Numpy`**: Ejercicios y fundamentos sobre computación numérica y manejo de arrays multidimensionales.
* **`/Pandas`**: Análisis y manipulación de datos estructurados, limpieza de datos y exploración.
* **`/Matplotlib` & `/Seaborn`**: Visualización de datos, creación de gráficos estadísticos y storytelling visual.
* **`/ML (Machine Learning)`**: Algoritmos y modelos predictivos divididos en:
  * **`/Supervisado`**: Modelos predictivos con datos etiquetados (Regresión Lineal, Regresión Logística, Árboles de Decisión, Bosques Aleatorios).
  * **`/No supervisado`**: Algoritmos de clustering y descubrimiento de patrones.
## 🛠️ Tecnologías Utilizadas

Las herramientas principales utilizadas en este entorno incluyen:
* Python 3.13
* Jupyter Notebooks
* Pandas, NumPy
* Scikit-Learn (Machine Learning)
* Matplotlib, Seaborn (Visualización)
